# 03-localize-customer-portal

Status: done

## Parent

`.scratch/frontend-i18n/PRD.md`

## What to build

Make the Customer Portal bilingual. A Customer must be able to select an Interface Language in the portal header and view Subscriptions and Order history, open renewal, and open Node switching flows with translated static interface text. Subscription and Order values remain exact domain data, while dates, times, and VND amounts follow the selected locale.

## Acceptance criteria

- [x] The Customer Portal header exposes the shared language selector.
- [x] Static UI text in the portal, Subscription list, Order history, renewal flow, and Node switching flow renders in Vietnamese and English.
- [x] Status labels, table headings, buttons, dialogs, empty states, and portal-local toast copy are translated.
- [x] Subscription identifiers, Node names, Region names, and API error details are not translated.
- [x] Portal dates/times and VND amounts use the shared locale-aware formatters.
- [x] The strict TypeScript production build succeeds.
