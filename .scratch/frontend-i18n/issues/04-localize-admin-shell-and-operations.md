# 04-localize-admin-shell-and-operations

Status: done

## Parent

`.scratch/frontend-i18n/PRD.md`

## What to build

Make the Admin shell and operational overview bilingual. An Admin must be able to change the Interface Language from the dashboard header, navigate through translated sidebar labels, and understand the Overview and Node Sync screens in either language without translating technical values such as IP addresses, ports, protocols, and Node names.

## Acceptance criteria

- [x] The Admin dashboard header exposes the shared `VI / EN` selector.
- [x] Static text in the sidebar, dashboard layout, Overview, and Node Sync screens renders in both languages.
- [x] Operational status badges, table headings, actions, empty/loading states, and local toast copy are translated.
- [x] IP addresses, ports, protocol names, timestamps' raw source values, and Admin-authored Node data remain unchanged.
- [x] Displayed dates/times and VND values follow the active Interface Language.
- [x] The strict TypeScript production build succeeds.
