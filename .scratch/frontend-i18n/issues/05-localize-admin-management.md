## What to build

Complete bilingual Admin management journeys for Nodes, Regions, Plans, Subscriptions, and Orders. An Admin must be able to list, filter, create, edit, confirm, and inspect each resource in Vietnamese or English, including associated forms, dialogs, and local feedback. Domain data entered by an Admin and backend error details remain unchanged.

- [x] Static UI text in Nodes, Regions, Plans, Subscriptions, and Orders management views is translated in both languages.
- [x] Their create/edit forms, filters, destructive-action confirmations, modal dialogs, badges, and local toast copy are translated.
- [x] Admin-authored names/descriptions, technical identifiers, and API error details remain verbatim.
- [x] Date/time and VND display uses the shared locale-aware formatters wherever these views present them.
- [x] No newly touched static management UI text is hard-coded in a component.
- [x] The strict TypeScript production build succeeds.
